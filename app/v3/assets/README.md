# Playful artwork

The first-preview mature character/world designs have been replaced. Current Home assets are `world-reference.webp`, `hero-girl-reference.webp`, `hero-boy-reference.webp` and `foreground-reference.webp`. They were reconstructed directly from the supplied mockup with the built-in image_gen tool on 2026-10-17. See [the exact reference prompts](../../../docs/PLAYFUL-REFERENCE-PROMPTS.md) and [art direction](../../../docs/PLAYFUL-ART-DIRECTION.md).

Hero and foreground WebP files preserve alpha transparency. PNG masters remain in the generating chat's `$CODEX_HOME/generated_images/01a149ab-ed61-72f2-ab71-9acdd28332a4/` directory. The app makes no runtime AI generation requests. Reference reconstruction is not a claim of pixel-identical extraction.

Activity rows use native colourful Playful SVG icons from `../icons.js`. Mission detail uses these character/action illustrations:

- `mission-bed-action.webp`: the reference hero making her bed.
- `mission-brush-action.webp`: the reference hero brushing her teeth.
- `mission-read-action.webp`: the reference hero reading with her kitten.

Created with built-in image_gen. See [the exact activity prompts](../../../docs/ACTIVITY-ART-PROMPTS.md). These replace the earlier still-life scenes.
