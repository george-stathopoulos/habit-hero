# Playful artwork

Created for Habit Hero with the built-in `image_gen` tool on 2026-10-17. Production files are local WebP assets. Transparency is preserved for hero and foreground cutouts. PNG masters remain in the generating chat's `$CODEX_HOME/generated_images/01a149ab-ed61-72f2-ab71-9acdd28332a4/` directory. No paid generation API is called by the application.
