# Habit Hero

A family-friendly habit and reward tracking Progressive Web App, with its own product website.

- **Website:** https://george-stathopoulos.github.io/habit-hero/
- **App:** https://george-stathopoulos.github.io/habit-hero/app/

Built as an early browser-based reconstruction of the original Habit Hero Android concept. Data is saved locally in the browser; no user accounts or cloud synchronization yet.

## Publishing

GitHub Pages: configure **Settings → Pages → Deploy from a branch → main / (root)**. The website is at the root and PWA is at `/app/`.

## Project stage

Early MVP, not feature-complete or a pixel-perfect APK conversion. Screenshots, full documentation, portfolio and blog launch announcements are deliberately deferred.
